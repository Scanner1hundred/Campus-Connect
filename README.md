# CampusMarket

A frontend prototype for a **Student Marketplace and Student Centre** application.

## Features
- Buy and sell electronic goods
- Rent electronics
- Browse product categories
- Browse Student Centre food vendors
- Add food items to a mock cart
- Responsive design

## Files
- `index.html` - application structure
- `style.css` - responsive styling
- `script.js` - frontend interactions

## Run locally
Open `index.html` in a web browser.

## Future backend integration
This frontend can later connect to the SQL database through an API for:
- Students
- Marketplace listings
- Marketplace orders
- Rentals
- Food vendors
- Food menu items
- Food orders
- Payments
- Reviews
